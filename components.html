Cards

Product cards repeat with different data, so they are built in JS with productCard(listing) instead of copied.

Product card (JS)
<!-- 1. In the page -->
<div class="row g-4" id="listingGrid"></div>

<script src="js/components.js"></script>
<script src="js/marketplace.js"></script>

// 2. In js/marketplace.js (listings come from data.js now, the API later)
const grid = document.getElementById('listingGrid');
grid.innerHTML = listings
  .map(listing => `<div class="col-sm-6 col-lg-4">${productCard(listing)}</div>`)
  .join('');

// Each listing looks like:
// { id: 1, farmId: 1, title: 'Wildflower Honey', farmName: 'Sunrise Farm',
//   price: 14, photo: 'images/wildflower.jpg', badges: ['certified', 'raw'] }

Navbar & footer

The navbar at the top of this page and the footer below are built by js/components.js. Edit them there once instead of in every HTML file.

Use on any page
<body>
  <!-- data-active marks the current page: map, marketplace or learn (leave it off elsewhere) -->
  <div data-component="site-nav" data-active="map"></div>

  <main class="container py-5">
    ...
  </main>

  <div data-component="site-footer"></div>

  <!-- components.js first, so the nav and footer show without waiting on the CDN -->
  <script src="js/components.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
